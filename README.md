# Julian Burnley Portfolio

A modern, responsive portfolio rebuild using semantic HTML, CSS Grid, Flexbox, CSS custom properties, and a small amount of JavaScript.

## Files

- `index.html` — portfolio page
- `css/main.css` — complete responsive styling
- `js/main.js` — mobile navigation and automatic footer year

## Before publishing

1. Replace placeholder `#` links for projects and résumé.
2. Add your actual GitHub and LinkedIn profile URLs.
3. Add screenshots or custom project images if desired.
4. Validate HTML and CSS.
5. Test keyboard navigation and mobile layouts.
6. Deploy to GitHub Pages, Vercel, Netlify, or your preferred host.
7. Connect `julianburnley.com`.
