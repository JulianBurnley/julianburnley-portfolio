Inclusive component design

Accessible ARIA Interface

An educational interface demonstrating keyboard-friendly behavior, meaningful states, and inclusive interaction patterns.

Role
Interaction design and development
Focus
Keyboard and assistive-technology access
Tools
HTML, WAI-ARIA, JavaScript
Source
Private portfolio repository

The challenge

Interactive controls must communicate their state and remain usable without a mouse while still adapting cleanly to smaller screens.

The approach

I paired semantic HTML with carefully managed ARIA attributes, visible focus treatment, skip navigation, and predictable keyboard behavior.

Key outcomes

  • Keyboard-operable tab interface
  • Correct state and relationship attributes
  • Visible focus and skip navigation
  • Responsive content tables
