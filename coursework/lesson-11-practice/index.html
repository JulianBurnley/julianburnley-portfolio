Internationalization

Writing Directions and Modes

The following English phrase has been translated into several languages. Some Asian languages can be written vertically or horizontally. When Western words are included, horizontal writing is often used so readers do not need to rotate the page.

English

Web development is a rewarding field.

Spanish

El desarrollo web es un campo gratificante.

German

Webentwicklung ist ein lohnendes Feld.

Chinese, Simplified

网络开发是一个有益的领域。

Japanese

This example is displayed horizontally because it includes the Western word “Web.”

Web 開発はやりがいのある分野です。

Hebrew

פיתוח אתרים הוא תחום מתגמל.
